# 인터뷰 스크립트 + 과거 무덤 부검 가이드

대상: 인스타 릴스로 카페·맛집을 저장하는 20~30대 지인 4~6명
1인 30분. **말(의견)이 아니라 과거 행동(실제 저장물)을 캔다.**
기록: `autopsy-sheet.csv` (1인 = 여러 행, 저장물 1개 = 1행)

> 진행 원칙 3가지
> 1. **"쓸 것 같아요?" 절대 묻지 않기.** → "지난주에 실제로 어떻게 했어?"로 바꾼다.
> 2. **화면을 같이 연다.** 기억이 아니라 실제 폴더/DM을 근거로.
> 3. **유도 금지.** 우리 앱 설명은 §D 실사용 프로브 전까지 하지 않는다.

---

## A. 워밍업 + 스크리너 (3분) — 이 사람이 우리 타겟인가

1. 인스타에서 카페·맛집 릴스 보면 보통 어떻게 해? (저장? DM? 캡쳐? 그냥 넘김?)
2. **"저장한다"고 하면, 정확히 어디에 저장해?** (여러 개면 다 말해줘)
3. **네이버 지도(또는 카카오맵) 즐겨찾기에 손으로 저장해?**
   - 안 한다면 → **왜 안 해?** (귀찮아서? 흐름 끊겨서? 몰라서?) ← **wedge 핵심 질문**
   - 한다면 → (제외 대상일 수 있음. 시트 `wedge_flag=N`로 표시하고 계속 진행은 하되 참고용)

> 판정 메모: `wedge_flag` = "던지는 저장은 하지만 지도 북마크는 안 씀" 이면 Y.

---

## B. 습관 재구성 (5분) — 최근 실제 사례

4. **가장 최근에 릴스 저장/DM한 카페·맛집이 뭐였어?** 지금 같이 찾아보자. (화면 열기)
5. 그거 저장할 때 무슨 생각이었어? ("가야지"? "언젠가"? "그냥 예뻐서"?)
6. 저장한 다음에 그거 **다시 열어본 적 있어?** 언제, 왜?
7. 실제로 **간 적 있어?** (Y/N) 안 갔으면 왜 못 갔어?

---

## C. 과거 무덤 부검 (15분) — 핵심 데이터

> "지난 저장물 15~20개만 같이 쭉 넘겨보자. 하나씩 딱 세 가지만 물어볼게."
> 저장물 1개마다 `autopsy-sheet.csv`에 1행씩 기록.

각 항목마다:
- **(track)** 어디서 저장? (DM 나에게 / 저장폴더 / 캡쳐 / 기타)
- **(remembered)** 이거 저장한 거 기억했어? (Y/N) ← 방치/까먹음
- **(revisited)** 저장 후 다시 열어봤어? (횟수)
- **(visited)** 실제로 갔어? (Y/N)
- **(still_want)** 지금 다시 보니 **아직도 가고 싶어?** (Y/N) ← 놓친 기회 = 진짜 통증
- **(findable_now)** 지금 이거 이름/위치 바로 찾을 수 있어? (Y/N) ← 흩어짐

> 진행 팁: 20개 다 못 채우면 최소 10개. "간 곳"과 "안 간 곳"이 섞이게.

---

## D. 실사용 프로브 (5분) — H2 저장 전환 (행동 관찰)

> 이제 우리 프로토타입을 연다. **설명 최소화, 직접 하게 둔다.**

8. (방금 부검한 릴스 중 안 간 곳 하나 골라) "이 릴스 링크를 여기 붙여넣고 저장해볼래?"
   - **관찰(말시키지 말고 지켜보기):**
     - 저장 성공했나? (Y/N)
     - 걸린 시간(대략 초)
     - 막힌 지점 / 헷갈린 지점
9. 다 하고 나서: **"방금 이거, 평소 DM으로 던지는 거랑 비교하면 어때?"**
   (더 쉽다 / 똑같다 / 더 번거롭다 — 그대로 받아적기)
10. "이거 지도에 모인 거 보니까 어때?" (반응 그대로 기록. 유도 금지)

---

## E. 마무리 (2분)

11. 이런 게 있으면 **얼마나 자주 쓸 것 같아?** (참고용 — 행동 아님, 지표로 쓰지 말 것)
12. 주변에 릴스 맛집 저장 많이 하는 친구 있어? (다음 참가자 리크루팅)

---

## 인터뷰 후 즉시 (참가자별 1분)

시트 상단 요약행에 기록:
- `wedge_flag` (Y/N)
- 부검 개수 / 그중 visited=Y 개수 / still_want=Y 개수 / remembered=N 개수
- 실사용: 저장 성공 여부, 소요 초, DM 대비 평가
- 인용할 만한 한마디(그대로)
