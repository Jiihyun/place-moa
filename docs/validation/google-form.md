# 구글폼 문항 (관심 규모 + 스크리너 정량 신호)

목적: 인터뷰(정성·깊음)를 보완하는 **정량 신호**. 커뮤니티/지인 단톡/인스타 스토리에 링크 뿌려 규모 파악.
**주의: 여기서 나오는 "쓰겠다"는 의도지 행동이 아님. 데크에서 보조 지표로만 인용.**
진짜 행동 지표는 인터뷰 부검 + 랜딩 사전신청(이메일) + 앱 저장 로그.

만드는 법: forms.google.com → 아래 문항 그대로 복붙. 응답 → 스프레드시트 연결.

---

## 섹션 1 — 스크리너 (타겟 판별)

**Q1. 인스타 릴스/게시물로 카페·맛집을 저장한 적 있나요?** (객관식·필수)
- 자주 한다 / 가끔 한다 / 거의 안 한다

**Q2. 저장할 때 주로 어디에 저장하나요?** (복수 선택)
- 인스타 DM "나에게 보내기"
- 인스타 저장 폴더(북마크)
- 화면 캡쳐
- 네이버/카카오 지도 즐겨찾기
- 노션·메모앱
- 그냥 안 하고 넘긴다

> 분석: **Q2에서 (DM/캡쳐/저장폴더)는 골랐지만 (지도 즐겨찾기)는 안 고른 응답 = 우리 타겟(wedge).**
> 이 비율이 핵심 정량 지표.

---

## 섹션 2 — 행동·통증 (과거 사실 기반으로 질문)

**Q3. 최근 한 달, 카페·맛집을 몇 개나 저장했나요?** (객관식)
- 0 / 1~3 / 4~10 / 10개 이상

**Q4. 저장해둔 곳 중 실제로 가본 곳은 대략 몇 %인가요?** (객관식)
- 0~20% / 20~40% / 40~60% / 60% 이상

**Q5. "저장해둔 걸 까먹고 못 간" 경험이 있나요?** (객관식)
- 자주 있다 / 가끔 있다 / 거의 없다

**Q6. 지금 저장해둔 맛집 목록에서 특정 한 곳을 바로 찾을 수 있나요?** (객관식)
- 바로 찾는다 / 한참 뒤진다 / 사실상 못 찾는다

---

## 섹션 3 — 관심 (사전신청)

**Q7. "릴스 링크 공유 한 번이면 AI가 장소를 지도에 자동 정리"해주는 앱이 있다면?** (객관식)
- 지금 바로 써보고 싶다 / 관심은 있다 / 별로

**Q8. 출시/베타 알림 받을 이메일 (선택)** — 단답
> Q8 응답 수 = 사전신청 수 = 관심 규모(보조 지표). 랜딩페이지 이메일과 합산.

---

## 분석 시 뽑을 숫자

- 응답 N명 중 **타겟(wedge) 비율** (Q1 자주/가끔 & Q2 조건)
- **방치율**: Q4에서 "0~40%" 비율
- **까먹음율**: Q5 "자주/가끔" 비율
- **못 찾음율**: Q6 "한참/못 찾음" 비율
- **사전신청 수**: Q8 이메일 수
