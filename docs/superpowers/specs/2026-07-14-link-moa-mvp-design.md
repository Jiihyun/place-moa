# 링크모아 (link-moa) MVP 설계

날짜: 2026-07-14
상태: 승인됨

## 문제

릴스·쇼츠·인스타 게시물에서 본 유용한 정보(레시피, 자기계발, 팝업, 옷, 책 추천 등)가
카톡 나와의 채팅, 인스타 저장, 갤러리 캡처에 산발적으로 흩어져서:

1. 나중에 볼 정보가 한 곳에 모이지 않는다.
2. 뭘 저장했는지 잊어버리고 다시 보지 않는다.

## 해결

iOS 공유 시트에서 바로 카테고리·메모를 붙여 한 곳에 저장하고,
"안 본 게시글" 탭과 게시물별 개별 알림으로 다시 보게 만드는 개인용 아카이빙 앱.

## MVP 범위

**포함:**
- iOS 공유 익스텐션(공유 시트 안 UI)으로 링크·이미지 저장
- 카테고리(유저 생성·관리) + 메모
- 링크 메타데이터 자동 추출 (제목·본문·썸네일) + 실패 시 수동 입력 폴백
- 홈 목록 / 카테고리 필터 / 검색 (제목·본문·메모)
- "안 본 게시글" 탭
- 게시물별 개별 로컬 알림 (날짜·시간 지정, 복수 가능)
- 상세 화면: 원문 열기(딥링크), 메모·카테고리 수정, 삭제

**제외 (v2 이후):**
- 서버·계정·기기 간 동기화 (단, 데이터 구조는 대비: UUID 키 + updated_at)
- Android (크로스플랫폼 스택이므로 추후 expo-share-intent로 추가)
- 주기 리마인드 알림 (전역 N일 주기 푸시) — 사용자 결정으로 MVP에서 제외
- 공유 익스텐션 안에서의 메타데이터 추출
- OCR, 태그, 공유 컬렉션 등

**배포 목표:** TestFlight로 배포해 메인 플로우(공유 → 저장 → 다시 찾기)에 대한
실사용자 피드백 수집. Apple Developer Program 계정 필요.

## 기술 스택

| 영역 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | Expo (React Native + TypeScript), prebuild(CNG) | iOS 우선, 크로스플랫폼 대비 |
| 공유 익스텐션 | expo-share-extension | 공유 시트 안 UI를 RN으로 렌더 (iOS 전용) |
| DB | expo-sqlite | 로컬 전용 |
| 알림 | expo-notifications | 로컬 예약 알림, 서버 푸시 불필요 |
| 메타데이터 | 유튜브: oEmbed API / 그 외: 폰에서 직접 OG 태그 파싱 | 서버 프록시 없음 |
| 빌드·배포 | EAS Build + TestFlight | |

## 아키텍처

```
[인스타/유튜브/사파리/갤러리]
        │ 공유
        ▼
공유 익스텐션 (RN UI, App Group 내 실행)
  - 링크/이미지 미리보기, 카테고리 칩, 메모 입력, 저장
  - App Group 공유 저장소의 "인박스"에 기록만 하고 종료
  - 이미지는 App Group 폴더로 복사
        ▼
메인 앱 (실행/포그라운드 진입 시)
  - 인박스 수거 → SQLite에 저장 → 수거 성공 후에만 인박스 삭제
  - 링크면 메타데이터 추출 (제목·본문·썸네일)
  - 이미지는 앱 내부 저장소로 이동
```

익스텐션은 iOS 메모리 제한이 빡빡하므로 최소 작업만 한다.
메타데이터 추출·알림 예약은 전부 메인 앱에서 수행한다.
공유 직후 앱을 열기 전까지는 목록에 "제목 없는 링크" 상태로 존재할 수 있다 (승인된 트레이드오프).

## 데이터 모델 (SQLite)

### items
| 컬럼 | 타입/의미 |
|---|---|
| id | UUID (서버 동기화 대비) |
| type | `link` \| `image` |
| url | 원본 링크 (link만) |
| source | `instagram` \| `youtube` \| `other` — URL에서 판별, 목록 아이콘용 |
| title | 추출 또는 수동 입력 |
| description | 추출된 본문/설명 |
| thumbnail_path | 로컬 썸네일 경로 (image면 원본 사본) |
| memo | 유저 메모 |
| category_id | FK, NULL = 미분류 |
| viewed_at | 처음 상세를 연 시각. NULL = "안 본 게시글" 탭에 표시 |
| metadata_status | `pending` \| `done` \| `failed` |
| created_at, updated_at | |

### categories
- id, name, icon(또는 색상), sort_order
- 첫 실행 시 기본 생성: 레시피, 자기계발, 팝업, 옷, 책
- 자유롭게 추가·수정·삭제. 삭제 시 소속 항목은 미분류로 이동

### item_alarms
- id, item_id(FK), fire_at, notification_id(iOS 예약 식별자, 취소용)
- 게시물당 알림 여러 개 가능

## 화면 구성

하단 탭 3개:

1. **홈** — 전체 목록 (썸네일 + 제목 + 출처 아이콘 + 카테고리 뱃지),
   상단 카테고리 칩 필터 + 검색바 (제목·본문·메모)
2. **안 본 게시글** — viewed_at IS NULL만 표시.
   - 상단에 안 본 총 개수 문구 (0개면 완료 문구).
   - 카테고리 칩 필터: 안 본 글이 있는 카테고리만 표시하고 칩마다 개수 뱃지.
     미분류 안 본 글이 있으면 "미분류" 칩도 표시.
   - 탭 뱃지: 안 본 개수 표시. 탭을 열면 뱃지는 사라지고(확인 처리),
     이후 새 항목이 저장되면 다시 나타남. 뱃지 확인과 무관하게 목록에는
     열어보기 전까지 계속 남음.
3. **설정** — 카테고리 관리 (추가·수정·삭제·순서)

**상세 화면:** 썸네일·제목·본문·메모, "원문 열기"(인스타/유튜브 딥링크),
이미지 전체 보기(image 타입), 메모·카테고리 수정, 개별 알림 설정(날짜+시간 피커),
삭제. 상세 진입 시 viewed_at 기록.

**공유 익스텐션 화면:** 미리보기 + 카테고리 칩(최근 사용순, 미선택 시 미분류)
+ 메모 입력(선택) + 저장 버튼. 저장 후 시트 닫히고 원래 앱으로 복귀.

## 메타데이터 추출

- 유튜브: `https://www.youtube.com/oembed?url=...` (공개, 안정적)
- 인스타·기타: 폰에서 직접 HTML GET → `og:title`, `og:description`, `og:image` 파싱.
  가정용 IP + 브라우저 User-Agent로 성공률을 높이되 100%는 아님.
- 실패 시: `metadata_status = failed`, 목록엔 도메인만 표시,
  상세에서 제목 직접 입력 유도 + 재시도 버튼.
- 썸네일은 다운로드해 로컬 저장 (원본 URL 만료 대비).

## 알림

- 게시물별 개별 알림만 (전역 주기 리마인드는 MVP 제외).
- 상세에서 날짜·시간 지정 → expo-notifications 로컬 예약.
  문구: "[제목] 다시 볼 시간이에요". 탭하면 해당 상세로 딥링크.
- 게시물 삭제 시 연결된 알림 모두 취소.
- 과거 시각 선택은 피커에서 차단.

## 엣지 케이스

- **중복 공유:** URL 정규화(추적 파라미터 제거) 후 중복이면 "이미 저장됨" 안내 + 기존 항목 열기.
- **인박스 유실 방지:** SQLite 기록 성공 후에만 인박스 항목 삭제. 중간 크래시에도 재수거 가능.
- **갤러리 원본 삭제:** 이미지는 앱 내부로 복사되므로 영향 없음.

## 테스트 전략

- 단위 테스트: URL 정규화, source 판별, OG/oEmbed 파서, DB 레이어(items·categories·alarms CRUD, 안 본 필터, 검색).
- 수동 검증 체크리스트 (실기기): 인스타 릴스 공유, 인스타 게시물 공유, 유튜브 쇼츠 공유,
  사파리 링크 공유, 갤러리 이미지 공유 — 각각 저장 → 앱 열어 메타데이터 확인 → 검색 → 알림 수신.
- 공유 익스텐션은 자동화가 어려우므로 수동 체크리스트로 커버.

## 결정 기록

| 결정 | 선택 | 이유 |
|---|---|---|
| 플랫폼 | 크로스플랫폼(RN+Expo), iOS 먼저 | 본인 기기 아이폰, 빠른 MVP |
| 저장 | 로컬 전용, 서버는 나중 | MVP 속도, 구조만 동기화 대비 |
| 메타데이터 실패 시 | 자동 시도 + 수동 폴백 | 인스타 차단 가능성 현실 반영 |
| 카테고리 | 유저 생성형 + 기본 프리셋 | 유연성 |
| 공유 흐름 | 공유 시트 안에서 저장 (B안) | 앱 전환 없는 UX, expo-share-extension으로 실현 가능 |
| 주기 리마인드 | MVP 제외 | 사용자 결정 — "안 본 게시글" 탭으로 대체 |
