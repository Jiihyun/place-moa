# 장소모아 (place-moa)
<img width="2400" height="1500" alt="장소모아 썸네일" src="https://github.com/user-attachments/assets/cc35efdc-1c38-4bd1-876a-5fda594aa537" />

장소모아는 인스타그램 릴스나 유튜브 쇼츠에 나오는 맛집·카페·명소를 내 지도에 모아두는 장소 아카이버입니다.
공유 버튼만 누르면 직접 등록할 필요 없이 앱이 장소를 찾아 지도에 핀으로 꽂아줍니다. 
또한 방문 기록과 "또 갈래요" 평가, 친구와 묶어 공유하는 것까지 한 곳에서 관리할 수 있습니다.

## 이런 불편함을 해결합니다
릴스나 쇼츠에서 가보고 싶은 곳을 보면, 대부분 캡처를 하거나 나에게 DM을 보내며 나름의 방법으로 저장해둡니다.
하지만 네이버·카카오 지도에 일일이 옮겨 등록하기는 번거로워, 대개 거기서 멈춥니다. 그렇게 장소가 앨범과 DM에 흩어지다 보니, 정작 약속을 잡을 때는 그 장소들을 꺼내보기 어렵습니다.

장소모아는 이 "옮겨 적는 수고"를 없앱니다.
공유 버튼만 누르면 앱이 알아서 장소를 찾아 지도에 정리해두기 때문에, 캡처하고 잊어버리는 대신 실제로 다시 꺼내 쓸 수 있습니다.

## 주요 기능
**공유 한 번으로 저장** — 공유 시트에서 장소모아를 고르면 게시물을 분석해 장소를 자동으로 저장합니다. 한 게시물에 여러 곳이 나오면 대기함에서 골라 담을 수 있습니다.
**지도 뷰** — 카테고리별 색·모양 핀으로 표시하고, 저장한 곳 근처에 가면 알려줍니다.
**검색·필터** — 이름·메모·지역·카테고리, 안 가본 곳, 또간집 기준으로 걸러 볼 수 있습니다.
**방문 기록** — 방문 횟수와 "또간집 / 한 번이면 충분" 평가를 기록할 수 있습니다.
**장소 묶어서 공유** — 여러 곳을 링크 하나로 묶어 보낼 수 있습니다. 받는 사람은 따로 검색하지 않아도 각 장소의 릴스나 리뷰를 바로 확인하고, 자기 지도에 그대로 담을 수 있습니다.

## 사용 대상
릴스·쇼츠에서 가보고 싶은 곳을 보면 캡처하거나 DM으로 남겨두지만,
지도에 일일이 등록하기는 귀찮아 결국 흐지부지되는 20~30대를 위한 서비스입니다.

가고 싶어서 캡처는 해두지만, 옮겨 적기가 귀찮아 그냥 쌓아두는 사람
네이버·카카오 지도에 하나하나 북마크하기는 번거로운 사람
